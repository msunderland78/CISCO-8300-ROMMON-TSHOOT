# Sanitized console and configuration evidence

Files below this directory are generated by `python3 scripts/repository_tools.py prepare` from local original console captures and configuration snapshots. Each keeps its original relative path beneath this directory.

Configured/supplied passwords, password hashes, password-prompt replies, recognizable access tokens, and private keys are redacted. Original local source files are not changed. Sanitized captures may also replace undecodable byte sequences when interpreted as UTF-8; they are readable troubleshooting evidence, not byte-exact serial archives or restorable configuration backups.

The publication manifest records the hashes of these sanitized files. Historical source checksums in older recovery notes refer to the original files, not these edited copies. Source-specific manual interpretation may still be needed; redaction does not certify absence of all possible sensitive information.

Do not edit generated files here directly: preparation regenerates them from local sources. A fresh clone has the sanitized evidence but not the private original logs or the local known-password list. Never replace an exact firmware/flash restore image with a sanitized text representation.
